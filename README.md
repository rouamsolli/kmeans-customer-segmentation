# kmeans-customer-segmentation

## Objective

The goal of this project is to segment customers
into groups based on their annual income and
spending score.

## Dataset

Mall Customers dataset.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- K-Means

## Machine Learning Approach

1. Load dataset
2. Explore data
3. Select features
4. Scale features
5. Find optimal K using Elbow Method
6. Apply K-Means
7. Visualize clusters
8. Evaluate using Silhouette Score
9. Interpret clusters

## Results

The customers were divided into several groups
based on their income and spending behavior.
